# Journali App 📖✨

## App Name & Purpose
**Journali** is a modern, minimalist digital journal and diary application designed in dark mode. It allows users to effortlessly capture their daily thoughts, personal stories, and memorable moments in an organized, secure, and intuitive space.

## Main Features
* **Full CRUD Operations:** Seamlessly add, view, edit, and delete personal journal entries.
* **Smart Search & Filtering:** Instantly search through entries and sort them by bookmarks or entry dates.

## Technologies Used
* **SwiftUI:** Modern declarative UI framework for building responsive user interfaces.
* **MVVM Architecture:** Clean separation of concerns with Model-View-ViewModel structure (`App`, `Models`, `ViewModels`, `Views`, `Utilities`, `Resources`, `Services`).
* **Observation Framework:** Efficient reactive state management (`@Observable`).
